# Hi, I'm Lewis 👋

I build web and mobile apps, from the backend through to the bit people tap on. I came to code the scenic route, but these days most of my evenings go on shipping things.

## What I'm working on

**[The Knitting App](https://www.theknittingapp.com)** · [App Store](https://apps.apple.com/app/tka-the-knitting-app/id6822035178)  
A pattern tracker for knitters. Upload a PDF or a photo of a pattern and it turns it into rows in your size that you tick off as you knit. I built the whole thing on my own, from the backend and database to the web app and the iPhone and Android apps. The import uses a few different AI models, each one picked by a benchmarking script rather than gut feel. The code is private, but I'm always happy to walk someone through it.

**Football sweepstake**  
A web app with live scoring from the BBC's sports data, plus a penalty shootout mini-game for settling ties. It ran for the 2026 World Cup.

**Artist portfolio and CRM**  
A gallery and sales-enquiry app for a non-technical artist, taken from prototype to production in under a week.

## How I work

- I use Claude Code every day and it writes a lot of my code, which is exactly why I care so much about tests.
- If I can't explain a change, it doesn't ship.
- I'd rather measure than guess. A lot of my favourite code is a small script that tells me something I didn't know.
